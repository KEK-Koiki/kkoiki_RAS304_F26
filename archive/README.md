# Archived course-template material

Original examples are retained in `course-template/docs/` for reference. They are not current project content and are not published by MkDocs. The current website uses the numbered folders under the root `docs/` directory.

Earlier authoring scripts are preserved in the development-history ZIP. They record superseded drafts and machine-specific workflows; do not run them to edit the current site. Use the focused tools in `tools/` instead. Git history also retains every published revision.
